# 入力換算雑音とチョッパ周波数の選定

非チョップ条件での入力換算雑音を評価した結果、目標未達のためチョッピングが必須であることを確認した。

| 指標 | 測定値 | 基準 | 判定 |
| :--- | :--- | :--- | :--- |
| 0.5〜100 Hz 積分 | 2.6475 µVrms | ≤ 1.0 µVrms | FAIL |
| 0.5〜250 Hz 積分 | 2.9501 µVrms | ≤ 1.5 µVrms | FAIL |
| 8 kHz での雑音密度 | 24.29 nV/√Hz | 参考 | - |

チョッパ周波数候補の比較（256 kHz からの分周、解析的推定）:

| 候補 | 対250 Hz比 | 推定雑音 | OTA利得 | 判断 |
| :--- | :--- | :--- | :--- | :--- |
| 4 kHz | 16 | 0.424 µVrms | 64.38 dB | 不採用（帯域分離が小さい） |
| **8 kHz** | 32 | **0.343 µVrms** | 58.39 dB | **採用** |
| 16 kHz | 64 | 0.289 µVrms | 52.39 dB | 不採用（改善量に対し切替増） |

※ 0.343 µVrms は理想変調と√2係数による解析的推定。スイッチ熱雑音・電荷注入・クロックフィードスルー等は未考慮。

# チョッパ実装検証と棄却判断

- 成立した内容: 理想×32コアを用いたスイッチ単体試験で、2 mVpp入力に対し 64.07 mVpp（利得32.0349、誤差+0.109 %）を確認。低電荷注入セル（100 ns非重複・半サイズダミーMOS・切替後1 µsブランキング）で差動誤差 0.083 µVrms を達成
- 不成立となった内容: PGA外部で矩形反転する単純チョッパ方式は、全バリエーションで約3 Vppの同相スパイクが発生し FAIL

| 方式 | 得られた利得 | 同相スパイク | 判定 |
| :--- | :--- | :--- | :--- |
| 外部入出力チョッパ | 4.23 V/V | 2.96 Vpp | FAIL |
| 100 pF保持容量 | 1.69 V/V | 2.01 Vpp | FAIL |
| 理想出力バッファ | 6.78 V/V | 3.11 Vpp | FAIL |
| 小型SW＋5 pF保持 | 2.84 V/V | 3.08 Vpp | FAIL |
| 入力のみ＋デジタル復調 | 0.599 V/V（同期利得） | 3.01 Vpp | FAIL |
| 理想入力変調対照 | 約0.997 V/V | 3.00 Vpp | FAIL |

- 判断: 8 kHzの周波数は維持するが、外部単純チョッパ方式は棄却。理想変調器でもスパイクが再現したため、主因はスイッチ寸法ではなく、容量帰還・CMFBループへ不連続信号を注入するトポロジにあると特定
- 次案: チョッピングを増幅器内部へ移し、入力差動対の前で変調、第1段と第2段の間で復調する内部チョッパ方式へ移行（第2段・出力CMFB・容量帰還PGA・ΣΔ ADC入力は連続時間のまま維持）

# 今週の成果と次工程

成果:
- 高利得2段OTAと容量比×32 PGA が TT/PVT で成立し、数値で合否判定できる状態になった
- 外部単純チョッパの不成立を製造前に発見し、原因（トポロジ由来）を特定できたことは重要な成果

次工程（優先度順）:
1. 内部チョッパ開ループ検証（第1段前変調／段間復調、100 Hz利得・8 kHzリップル・VCM確認）— 最優先
2. 内部チョッパを容量帰還へ統合した PGA32 閉ループ（利得誤差1%以下、PM 60°以上）
3. CMFB専用ループ解析（全PVTでPM 60°以上）
4. 雑音再評価（sampled/transient noise、スイッチ雑音、電極源20〜100 kΩを含む）
5. バイアス回路の process-aware 化（理想VBN置換、SF電流余裕の拡大）
6. Monte Carlo（入力対・容量比・スイッチ非対称・オフセット・CMRR）
7. レイアウト抽出（5 MΩ検出網の実装方式、post-layout PVT）

現在のプロジェクト判定: **継続可能**。OTA/PGAの中核は有望。チョッパ配置とバイアス回路が次のクリティカルパス。現段階では製造性能確定とは扱わない。
